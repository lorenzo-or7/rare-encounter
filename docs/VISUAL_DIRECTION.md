# Visual direction — approved and proposed

Rare Encounter: editorial, ethereal chromatic mystery, premium but not generic AI. Brand logo approved: geometric RARE / smaller tracked ENCOUNTER, interwoven motif, violet-cyan accent. Original React Bits Stepper, Border Glow, Holo Card in assigned surfaces. Liquid Flow transition landing -> preparation.

Landing narrative: The Encounter; Beyond the Obvious; How Discovery Works; Every Connection Is Different; Begin Your Journey. Floating Archetype Cards: three approved visual mystery cards (Ethereal violet, Instinctive cyan, Radiant warm gold), matching Tap to discover icon and decorated question mark. Interactive Discovery: tilt/glow on hover, brief phrase reveal on click/tap, no modal. Cards are editorial, not algorithm classes. Text in screenshots should be rebuilt as real localized DOM text/controls, not treated as interactive images.

Preparation: 30 A Glimpse, 60 The Journey, 90 Deep Connection; three cards desktop, stacked mobile; user selects and confirms with distinct CTA; cannot alter duration after start. No confirmed default selection.

Quiz: one question per view; text/photo/icon+text choices; horizontal flow next/back; selected response Energy Pulse + Spring Press; auto advance after ~250–350ms feedback with durable save; continuous progress, pause/resume/save/restart, responsive category atmosphere. Motion reduced alternative.

Result: mystery card flips when activated, original React Bits Holo Card only if appropriate; gallery of Soul/Hidden/Alternative with explanations; Share Studio single/collection, PNG 1080x1920 and 1080x1350.

## Visual ideas NOT automatically approved
Encounter Thread, exact timing/easings, most decorative atmospheric treatments, a universal light-mode switch, 60 as preselected mode, any new animations beyond the defined direction.

## Visual QA
Real screenshots desktop/tablet/mobile; no clipping; type hierarchy; compare against provided reference images; control glow, blur, motion and image weight; assess accessibility/performance. User approval is the visual quality gate.
